## How to use these notes

- Each module file starts with an outline, is organized per lecture topic, and ends with **Key exam takeaways** (traps + checklists). Read the takeaways first, then drill the worked examples.
- Every module contains condensed fully-worked numerical examples for each method — cover the solution and re-solve by hand.
- Each module includes **flowcharts** (solution workflows, method-selection guides, e.g. simplex loop, Big-M vs two-phase, MODI pipeline, Johnson's rule, game-solving workflow) as embedded PNGs in `figures/m*.png`, generated from editable LaTeX-TikZ sources in `figures/tex/`. Rebuild any flowchart with the Tectonic engine and convert PDF to PNG (see `../convert_pdfs_to_md.py` header for the Python environment; compile via `tectonic.exe -o <dir> <file>.tex`).
- Quantitative graphs (feasible-region plots for all four graphical-method outcomes, convex vs non-convex sets, IBFS cost comparison, 2x4 game envelope) are in `figures/g_*.png`, generated by the functions in `figures/make_graphs.py` (matplotlib + seaborn) — rerun that script to regenerate them.
- Key lecture graphs and tables are embedded as images from `../transcripts/images/lecN/` (125 figures total: feasible-region plots, tableau slides, Gantt charts, payoff plots).
- Full word-by-word transcripts (with timestamps) remain in `../transcripts/lecN.md` if you need to revisit any explanation.

## Exam strategy (suggested)

1. Master Module 1 first — simplex tableau reading underlies duality, sensitivity, and game-LP conversion.
2. Memorize as templates: primal–dual conversion rules, dual simplex steps, Hungarian steps, Johnson's rule, dominance order, and the game-to-LP substitution (x_i = p_i / V).
3. Practice detection drills: multiple vs unbounded vs infeasible (tableau + graphical signs); saddle-point check before any game computation.
4. Watch for known lecture errata flagged inside the notes (e.g. Module 3 DP value 10000/3, Module 4 G5 total) — trust the corrected math.
5. Finish with the quiz banks in Modules 1, 2, 4, 5 under timed conditions.
