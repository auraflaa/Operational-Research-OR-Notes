# Previous-Year Questions and Problem Solving

Practice material for the NPTEL **Operations Research** course (noc26_ma85, Prof. Kusum Deep, IIT Roorkee).

## About these questions

- The same course ran earlier as **noc19_ma29 / noc20_ma45 / noc24_ma55** with an identical 8-week syllabus. NPTEL's proctored final papers are **not published**, so this folder contains the next best thing:
  1. **Genuine in-lecture quiz/exercise/homework questions** from the transcripts (each marked with its *Source: Lecture N* tag) — these are the instructor's own exam-style items.
  2. **New practice questions** written in the exact NPTEL assignment style (MCQ + numerical + short answer) from the course examples, every numerical answer solved and cross-checked (LP optima verified with a solver; sequencing answers checked against exhaustive permutation search).
- Difficulty and format mirror the real weekly assignments: 10 questions per week.

## Exam pattern (official, from the course page)

| Component | Weight | Rule |

|---|---|---|

| Weekly assignments (8) | 25% | Best 6 of 8 averaged |

| Proctored final exam (100 marks) | 75% | Hall-ticket exam |

| Eligibility | — | Assignment avg ≥ 10/25 **and** final ≥ 30/75, else no certificate |

## How to use

1. Study the corresponding `Notes/Module*.md` first.
2. Attempt each weekly set closed-book in ~60 minutes, then check against the key and read every worked solution (even for questions you got right).
3. Finish with `Mock_Final.md` under timed 3-hour conditions.
4. Revisit the **Key exam takeaways** in each module file for anything you miss.
